# Clothing Brand Sales & Profitability Analysis

## Project Overview
This project uses Power BI to analyze a clothing brand's sales performance, profitability, products, orders, and retailer performance.

The goal is to turn business data into meaningful insights through an interactive dashboard that supports better business understanding and decision-making.

## Dashboard Pages

The report consists of five interactive pages:

1. **Home Page** – Main dashboard navigation.
2. **Products** – Analysis of product performance.
3. **Orders** – Analysis of order-related data.
4. **Sales** – Sales performance analysis.
5. **Retailers** – Analysis of retailer performance and distribution.
